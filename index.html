RELAY: Autonomous Supply Chain Exception Resolution Agent

RELAY is an autonomous Agentic AI platform built to detect, investigate, and resolve supply chain disruptions across Procurement, Logistics, and Inventory in real time.
By evaluating operational trade-offs, RELAY delivers optimal resolutions, enforces human approval for high-risk actions, and commits verified database updates.

The Problem Statement

1. The Real-World Disruption

Supply chains face daily unexpected disruptions: shipments get stuck in transit, suppliers miss promised delivery dates, and warehouses run out of stock. These delays trigger severe cascading delays down to the end-customer.

2. Why Traditional ERPs Fail

Existing systems use rigid, hardcoded rules like "if delayed → reroute shipment". They cannot check whether a nearby warehouse already has spare inventory, or if expedited freight is cheaper than switching vendors.

3. The Manual Investigation Bottleneck

Managers must manually inspect disconnected spreadsheets and databases across procurement, transportation, and inventory—wasting 4+ hours per exception and causing expensive errors.

4. The RELAY Solution: Autonomous Agentic AI

RELAY introduces an autonomous Agentic AI system that dynamically investigates and resolves supply chain disruptions across Procurement, Logistics, and Inventory, executing verified database updates and enforcing human approval for high-risk actions.

Literature Review

Modern supply chain resilience and automated disruption management build upon key developments across operational research and Agentic AI:

1. Supply Chain Visibility (Ivanov et al., 2021):
Demonstrated that disruptions ripple rapidly across operational silos. Mitigating delays requires concurrent visibility across procurement, inventory, and logistics rather than isolated local fixes.

2. Goal-Driven Autonomous Agents (Russell & Norvig, 2020):
Established that complex environments require autonomous perception-action cycles, where agents dynamically inspect the environment state and execute goal-directed steps.

3. Tool-Augmented LLMs (Schick et al., 2023 / Toolformer):
Proved that connecting language models to structured database tools eliminates hallucination, allowing AI to safely inspect live inventory and purchase orders.

4. Stateful Agent Graphs (LangGraph, 2024 / Wu et al., 2023):
Introduced cyclic state graphs that separate multi-step reasoning into specialized Investigation and Resolution agents with state persistence and reversible workflows.

5. Human-in-the-Loop Operations:
Operations research demonstrates that high-impact actions (e.g., supplier switching, expensive express reroutes) must incorporate human authorization gates before execution.

Research Gap & Key Innovations

  • • Agentic AI (LangGraph & Grok API): Replaces static IF-THEN ERP scripts with dynamic multi-agent reasoning.
  • • Predictive Machine Learning: Predicts stockouts, scores supplier reliability, and optimizes buyer expenditure.
  • • Cross-Silo Intelligence: Automatically queries Procurement, Logistics, and Inventory in one flow.
  • • Real Action Execution: Executes verified PostgreSQL database updates instead of generating text advice.
  • • Multi-Criteria Scoring: Evaluates options across Cost (₹), Resolution Time, Risk, and Feasibility.
  • • Human Approval Gate: Prevents unauthorized high-cost actions through interactive manager sign-off.
  • • Full Audit Traceability: Records every tool call, reasoning step, and state mutation in an immutable log.

Key Advantage:
Every customer order traces directly to its shipment, assigned carrier, warehouse stock, and supplier PO.

2. 3-Phase Agentic Workflow

Phase 1 — Deterministic Detection:
Factual SQL queries verify delivery dates against SLAs and detect inventory stockouts with 100% precision—zero LLM hallucination.
Phase 2 — LangGraph & Grok API Investigation:
Orchestrated via LangGraph, specialized agents use the Grok API LLM to dynamically call 15+ database tools across procurement, logistics, and inventory to uncover the root cause.
Phase 3 — Predictive ML & Execution:
Integrates ML models (stockout forecasting, vendor reliability scoring, buyer cost reduction), requests human approval for high-risk actions, and commits live database updates.

System Capabilities

Six core domain toolkits that empower the agent to investigate root causes and execute resolutions

Procurement Tools

  • get_supplier: Inspect vendor details & capacity
  • get_supplier_performance: Check historical lead times & delays
  • get_purchase_order: Query open PO items and delivery dates
  • find_alternative_supplier: Identify qualified backup suppliers
  • execute_supplier_switch: Reassign PO to approved alternate vendor

Logistics Tools

  • get_shipment: Fetch live shipment location & carrier SLA
  • get_carrier: Evaluate carrier on-time delivery rates
  • get_route: Inspect origin, destination, and transit nodes
  • find_alternative_carrier: Search available express freight options
  • execute_shipment_reroute: Mutate route & carrier assignment in DB

Inventory & Warehouse Tools

  • get_inventory: Check real-time stock levels per warehouse
  • find_available_inventory: Locate spare stock in regional hubs
  • find_alternative_warehouse: Identify closest hub with capacity
  • calculate_business_impact: Quantify stockout and late penalty risk
  • execute_inventory_transfer: Transfer units directly between hubs

Deterministic Detection Rules

  • Shipment Delay: Estimated Delivery Date > Promised Customer SLA
  • PO Delay: Expected delivery date has passed without receipt
  • Inventory Stockout: Available warehouse inventory < order requirement
  • Supplier Bottleneck: Purchase order size > vendor available capacity

Resolution Trade-Off Scoring

  • Estimated Cost: Calculates direct intervention expense (₹)
  • Expected Time: Measures hours/days saved to protect SLA
  • Inventory Impact: Prevents depletion of donor warehouse stock
  • Operational Risk: Assesses risk level (Low / Medium / High)
  • Feasibility Score: Verifies partner availability before proposing

Approval Gate & Audit Trail

  • High-Impact Filter: High-cost supplier switches require approval
  • Interactive UI Modal: Managers review reasoning and click Approve/Reject
  • Live DB Mutation: Executes SQL changes only after sign-off
  • Immutable Audit Trail: Logs timestamp, agent steps, inputs, and outputs
